ML/AI
Tobias Ladner, Matthias Althoff (TU Munich) · arXiv:2609.15533 · Sep 14, 2026

A sobering result for the interpretability field: across five open-weight model families (GPT-2, Gemma 2/3, Llama 3.2, R1-Distill-Qwen), small, semantically irrelevant input perturbations flip which sparse "interpretable" features dominate a circuit explanation. Breaking the 1.58-bit Barrier for Ternary LLMs

ML/AI
Evangelos Georganas et al. · arXiv:2609.16338 · Sep 14, 2026

Ternary (BitNet-style) LLMs are usually packed at 1.625 bits/weight under the assumption weight values split roughly evenly across {-1, 0, 1}. This paper shows that across 29 real ternary models, zero-weights actually make up as much as 51.5% of parameters — far skewed from that assumption. Their new format, BITCOS (a presence bitmap plus a compacted sign vector), exploits that skew to push storage below the textbook 1.58-bit information-theoretic bound, a nice practical win for edge deployment of ternary models.

Test-Time Unlearning via Sparse Autoencoders (ARIA)

ML/AI
Pingzhi Li, Jinhao Duan, Tianlong Chen (UNC Chapel Hill) et al. · arXiv:2609.16229 · Sep 14, 2026

Instead of retraining a model to "unlearn" some piece of knowledge — which degrades general utility and can be reversed by further fine-tuning or jailbreaks — ARIA leaves the weights untouched and uses sparse-autoencoder latents to detect when generation is entering a "forget-related" state, gating the output only at that point. It reframes unlearning as an inference-time interpretability problem rather than a training-time one, which sidesteps a lot of unlearning's usual failure modes.

Quantifying the Memorization-to-Generalization Transition: Scaling Laws and Phase Structure in Grokking

ML/AI
Anish Kataria (Princeton) · arXiv:2609.10657 · Sep 10, 2026

Maps grokking across 384 MLP configurations on modular arithmetic tasks and fits a power law for time-to-generalization. Data quantity dominates: the fitted exponent for dataset size is ≈ −2.04 versus ≈ −0.27 for model width, meaning doubling the data speeds up generalization roughly 4x while doubling width buys only ~1.2x. The paper also finds a sharp phase boundary in weight decay that separates grokking from non-grokking regimes — useful ammunition for theories of why grokking happens at all.

ToolGrad: Efficient Tool-Use Dataset Generation with Textual Gradients

Lab
Google Research · Sep 10, 2026

An "answer-first" method for synthesizing tool-use training data: instead of prompting for a scenario and hoping a valid tool-call chain follows, ToolGrad builds a valid ground-truth API call chain first, then works backward to generate a matching user prompt, using an iterative propose/execute/select/update loop borrowed from prompt-optimization "textual gradients." The resulting dataset achieves near-100% validity, and models trained on it match proprietary SOTA LLMs on out-of-distribution tool-use benchmarks — a clean fix for a persistent synthetic-data-quality problem.
